PIXELARIA GAMES - Proyecto final PHP y MySQL

DESCRIPCION
Pixelaria Games es una página de catálogo de videojuegos. Los juegos ya están cargados
previamente en la base de datos. La página permite recorrer el catálogo, registrarse,
iniciar sesión y administrar usuarios desde una cuenta administradora.
No se crean videojuegos desde la página y no se realizan compras.

REQUISITOS
- XAMPP con Apache y MySQL iniciados.
- PHP con PDO y pdo_mysql habilitados.
- Visual Studio Code y navegador.

INSTALACION
1. Copiar la carpeta pixelaria_games dentro de C:\xampp\htdocs\
2. Iniciar Apache y MySQL desde XAMPP.
3. Entrar a http://localhost/phpmyadmin/
4. Abrir la pestaña SQL e importar/ejecutar el contenido de database.sql.
5. Revisar los datos de conexion.php si tu MySQL usa otra contraseña.
6. Entrar a http://localhost/pixelaria_games/index.php
7. Crear una cuenta desde Registrarse.

CREAR ADMINISTRADOR
1. Abrir una terminal y ejecutar:
   php -r "echo password_hash('admin123', PASSWORD_DEFAULT);"
2. Copiar el hash que aparece.
3. En phpMyAdmin, seleccionar la base pixelaria_games y ejecutar esta consulta,
   reemplazando PEGAR_HASH_AQUI por el hash obtenido:
   INSERT INTO usuarios (nombre, apellido, dni, email, password_hash, rol)
   VALUES ('Admin', 'Pixelaria', '00000000', 'admin@pixelaria.com', 'PEGAR_HASH_AQUI', 'admin');
4. Ingresar con admin@pixelaria.com y la contraseña admin123.
   Cambiar esa contraseña después de la primera prueba.

IMAGENES Y LOGO
- En los encabezados se dejó un espacio para img/logo-placeholder.png.
- Crear la carpeta img y guardar allí el logo exportado desde Canva con ese nombre.
- Para la portada, completar el bloque .imagen-portada de index.php con una imagen.
- Para cada juego, completar el espacio de imagen en la tarjeta del catálogo.
- No se incluyeron imágenes para que puedas elegirlas vos.

FUNCIONES DEL PROYECTO
- Catálogo de videojuegos cargados previamente en MySQL.
- Registro e inicio de sesión de usuarios.
- Cierre de sesión con PHP.
- Contraseñas guardadas con password_hash y verificadas con password_verify.
- Panel personal para usuarios.
- Panel administrador para buscar, editar, archivar y reactivar usuarios.
- Conexión a MySQL mediante PDO y consultas preparadas.

IMPORTANTE
El catálogo es solamente demostrativo. No hay carrito, compras ni pagos.
Probá cada función en tu instalación antes de presentarlo.
